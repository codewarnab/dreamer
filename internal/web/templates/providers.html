Dreamer tracks the health, token consumption, and runtime metrics of your active AI providers. Adding a codebase project and running your first analysis will populate this dashboard.

Setup Guide:
1. Run Setup TUI to configure your AI credentials & default models:
dreamer setup
2. Register a codebase project for scanning:
dreamer add <absolute-project-path>
3. Trigger the daemon or execute a one-shot analysis scan:
dreamer analyze --path <project-path>
